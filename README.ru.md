# MacrosRecorder

**Запись и воспроизведение макросов мыши и клавиатуры для Windows, включая закупку снаряжения в WARDOGS.**

[English](README.md) · [Keysharp](https://github.com/keysharp-org/Keysharp)

MacrosRecorder — скрипт Keysharp с отдельными слотами F1–F12 для каждого окна приложения. Он записывает клики, прокрутку, нажатия буквенных клавиш, модификаторы, удержания и перетаскивания.

## Сценарии

- **Закупка в WARDOGS:** записать выбор снаряжения у торговца и повторять его, когда открыт тот же экран магазина.
- Повторять последовательности в приложениях Windows: переходы по меню или заполнение типовых форм.

## Быстрый старт

1. Установите [Keysharp](https://keysharp-org.github.io/KeysharpDocs/howto/Install.htm) для Windows.
2. Скачайте и запустите `src/purchase-macros.ks` через Keysharp.
3. Откройте нужное приложение, нажмите **Ctrl + F1**, выполните действия и снова нажмите **Ctrl + F1**.
4. Вернитесь к тому же экрану и нажмите **Shift + F1**. Другие слоты работают аналогично.

| Сочетание | Действие |
|---|---|
| Ctrl + F1–F12 | Начать или завершить запись |
| Shift + F1–F12 | Воспроизвести макрос |
| Ctrl + Esc | Отменить запись |
| Shift + Esc | Остановить воспроизведение |
| Левый Ctrl + правый Ctrl | Показать слоты, пока клавиши зажаты |

Перед завершением записи отпустите записываемые клавиши и кнопки. Оверлей и синтетический ввод могут работать не во всех играх и режимах экрана. Сначала проверьте короткую последовательность и учитывайте правила приложения или игры.

## Пример: закупка в WARDOGS

Откройте торговца при том размере окна и расположении интерфейса, которые будут использоваться при воспроизведении. Запишите выбор снаряжения и сохраните слот. Перед запуском снова откройте тот же экран магазина. Начните с небольшой пробной закупки; если игра пропускает действия, увеличьте задержки. Это независимый проект сообщества, не связанный с разработчиками WARDOGS.

## Настройки и файлы

Записи хранятся локально в `macros/<приложение>_<идентификатор>/F1.txt` и не входят в репозиторий. В файле можно изменить `name`, `delay_min`, `delay_max`, `move_ms`, `singlePointDelay` и `samePointRadius`. Задержки указаны в миллисекундах, радиус — в пикселях. При перезаписи настройки сохраняются, а предыдущая версия копируется в `.bak`.

Новые записи сохраняют размер окна; при несовпадении воспроизведение остановится. Для старых записей без размера проверка невозможна. Если путь приложения изменился, скрипт может предложить скопировать похожий макрос после подтверждения. Совпадение имени EXE или класса окна приблизительно, поэтому проверяйте пути.

Работа координат зависит от окна, масштаба и поддержки ввода приложением. Проверьте удержания, перетаскивание и прокрутку в нужной программе. Файлы макросов могут содержать пути и последовательности ввода — проверяйте их перед публикацией.


## Структура проекта

```text
src/purchase-macros.ks  Основной скрипт Keysharp
.github/workflows/      Проверки и публикация релизов
tests/                  Проверка расположения записей
macros/                 Личные записи (не отслеживаются Git)
```

## Релизы и разработка

Скачайте архив со [страницы релизов](../../releases/latest), распакуйте его и запустите скрипт из `src/`. Сохраните структуру папок: записи будут храниться в `macros/` внутри распакованной папки.

GitHub Actions проверяет проект при push и pull request. Для публикации отправьте тег версии, например `v1.0.0`: workflow соберёт архив со скриптом и документацией и создаст релиз с автоматически сформированным описанием. Не добавляйте личные записи в репозиторий.
